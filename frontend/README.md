# Локальный чат

Создайте хеш пароля в закрытом режиме из папки `backend/` командой `uv run python scripts/hash_password.py`. Скрипт дважды запросит пароль и выведет только хеш Argon2id. Задайте его как `RC_PASSWORD_HASH` в окружении процесса backend (например, через закрытый `.env`, не отслеживаемый Git, подключённый менеджером процессов). Не помещайте обычный пароль в команду, отслеживаемый файл или браузерную сборку. Без хеша backend не запустится.

Для локальной разработки задайте `RC_PUBLIC_ORIGIN=http://localhost:5173` (это значение используется по умолчанию), запустите backend из `backend/` командой `uv run uvicorn app:app --host 127.0.0.1 --port 8000`, затем запустите frontend из `frontend/` командой `npm run dev`. Откройте именно тот адрес Vite, который указан в `RC_PUBLIC_ORIGIN`. Vite перенаправляет `/auth` и `/ws` на backend. Если Vite выбрал другой порт или вы открыли `127.0.0.1` вместо `localhost`, измените `RC_PUBLIC_ORIGIN`, чтобы он точно совпадал с адресом браузера. Локальный режим принимает только loopback-адреса; публичный адрес требует удалённого режима и HTTPS.

Для удалённого использования соберите frontend командой `npm run build` и задайте `RC_AUTH_MODE=remote`, `RC_PUBLIC_ORIGIN=https://your-chat-host.example` и `RC_PASSWORD_HASH`. FastAPI обслуживает собранный frontend и API по одному адресу. Для удалённого режима нужны HTTPS и собранный `frontend/dist` (или каталог, заданный через `RC_FRONTEND_DIST`). Завершайте TLS на доверенном туннеле или прокси и перенаправляйте запросы на FastAPI, привязанный к `127.0.0.1`; не открывайте порт 8000 напрямую. Запускайте один worker backend: chat bridge и ограничитель частоты входа хранят состояние в памяти процесса. Надёжно сохраняйте `RC_AUTH_DATABASE_PATH` (по умолчанию `backend/data/auth.sqlite3`) рядом с базой переписок. Локальный cookie называется `rc_session` и не использует `Secure` при HTTP-разработке; удалённый режим использует `__Host-rc_session` с `Secure`. Оба cookie имеют атрибуты `HttpOnly`, `SameSite=Strict`, привязаны только к текущему хосту и истекают через семь дней. Выход отзывает сессию на сервере и закрывает активный чат-сокет. Для защищённых HTTP-изменений требуются точный Origin и CSRF-токен; для WebSocket — точный Origin и действующая сессия. Разрешение CORS для всех источников в production не включено.

Backend выбирает один локальный проект. По умолчанию это корень данного репозитория. Чтобы использовать другой существующий каталог, задайте `RC_PROJECT_PATH` в окружении backend. Браузер никогда не отправляет путь файловой системы.

Клиент отправляет `{"type":"submit_prompt","text":"..."}`. Сервер отправляет `ready`, `turn_started`, `assistant_delta` (с `text`), `agent_status` (со `status`), `turn_completed` (со `status`) или `error` (с `code`). Поддерживается одно подключение браузера и один активный ответ; закрытие соединения прерывает выполняющийся ответ.
